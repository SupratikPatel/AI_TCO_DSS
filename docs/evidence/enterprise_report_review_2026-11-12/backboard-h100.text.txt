On Qwen3.8-Flash-Next across eight NVIDIA H100 GPUs, Backboard's BF16 inference produced up to 12.8× higher p90 interactivity, up to 13.6× faster time to first token, and up to 2.2× higher output throughput than SGLang at FP8.
For agentic AI, inference performance is about more than how many tokens a GPU can process. It is about how quickly an agent can get started, how smoothly it can generate an answer, and how well the serving engine maintains that experience as more sessions fight for compute.
That is what makes the SemiAnalysis AgentX benchmark an important test. Rather than relying on isolated, single-turn prompts, AgentX models the behavior of real coding agents: long, multi-turn conversations, shared context, pauses between turns, parallel subagents, and repeated KV-cache reuse.
In our comparison using Qwen3.8-Flash-Next on eight NVIDIA H100 GPUs, Backboard running at BF16 precision delivered much better 90th percentile (p90) interactivity than the published SGLang FP8 results at every concurrency level tested. The largest advantages appeared at the low- and high-concurrency ends of the test, where Backboard reached up to 12.8× the interactivity of SGLang.
Importantly, we achieved these results without compromising precision. Backboard's inference engine retains BF16 precision, where the SGLang reference uses FP8.
Better interactivity at all levels
Interactivity measures how quickly tokens arrive once generation has begun. It’s a vital metric for agentic workloads, where users and other agents need to consume intermediate output and continue working with as few delays as possible.
At one concurrent session, Backboard delivered 12.8× higher p90 interactivity than SGLang. The advantage held even as concurrency increased: 7.0× at 12 sessions, and 5.0× at 16.
12.8× higher p90 interactivity than SGLang.
The results were more closely matched at mid-tier concurrency levels. Backboard was 1.1× ahead at both four and eight sessions. Still, that makes clear that gains apply across workloads, not just in narrow conditions.
The difference is more relevant at higher concurrency levels. Even with 16 active sessions, Backboard maintained 5.0× the p90 interactivity of the SGLang reference. That translates into a far more responsive token stream.

Faster first tokens at every concurrency level
Interactivity describes what happens after generation begins. Time to first token (TTFT) is still important, as it measures the wait before that work takes place.
Here, Backboard also led at every tested concurrency level, delivering between 1.6× and 13.6× faster p90 TTFT than SGLang.
The largest improvement came at one concurrent session, where Backboard reduced the p90 wait by 13.6× — more than an order of magnitude. At 12 sessions, the first token arrived 3.1× sooner; at 16 sessions, it arrived 2.5× sooner.

These improvements are essential for agentic systems. A coding agent may need to issue several requests, inspect intermediate results, delegate tasks, and resume earlier conversations. Reducing the time spent waiting for each response to begin can improve the responsiveness of an entire workflow, not just an individual model call.
The combination of faster TTFT and higher interactivity is powerful: Backboard improved generation speed across the pipeline, all the while operating at high precision.
Higher output throughput across the entire test
The user experience is most important, but that doesn’t have to come at the expense of behind-the-scenes performance. As an infrastructure operator, you also need to maximize the amount of useful work you can get from available GPUs.
Backboard mustered between 1.1× and 2.2× the output token throughput per GPU across all five concurrency levels. The strongest result came with one session, while the advantage held at 1.3× with 16 sessions.

Measuring performance under realistic agent workloads
AgentX exposes the trade-offs that simpler inference benchmarks can miss. Its workload represents long-running, multi-turn coding sessions, including shared context, subagent activity, and pauses between turns. Its concurrency setting represents live session trees rather than simply the number of simultaneous HTTP requests.
This is important because serving an agentic workload requires more than maximizing tokens per second in an isolated generation request. The inference engine has to manage prefill and generation, share GPU resources across sessions, and maintain responsive token delivery as workloads become more complex.
Our objective with Backboard is to improve those underlying execution and scheduling decisions through software, making existing GPU infrastructure more productive without requiring you to change the underlying model or reduce its precision.
Backboard's measurements use BF16, while the published SGLang reference uses FP8. This isn’t a matched-precision comparison, so the results shouldn’t be interpreted as isolating the inference engine's advantage from every possible configuration difference.
More responsive inference, more useful GPU capacity
The AgentX results show two important dimensions of Backboard's performance lead. First, users can receive their first tokens sooner and see faster streaming once generation starts. You, in turn, can process more output tokens with the same GPU resources.
The gains are not identical at every concurrency level, and we think that’s worth showing rather than hiding. At four and eight sessions, the interactivity gap is modest. At 12 and 16, it becomes much larger. Backboard also maintains higher output throughput across the tested range.
For teams building agentic applications, that combination matters. Faster token generation can make individual interactions feel more responsive, while higher throughput creates room to serve more work on existing infrastructure.
We’ll continue testing across models, hardware generations, precisions, and workload patterns, with an emphasis on showing not only where Backboard leads, but also where the performance differences narrow and where we can make further improvements.
